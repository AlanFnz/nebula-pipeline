# Changelog

## 0.128.0 · 2026-11-23

Studio Graphite now extends to the effect list and preset previews. The list highlights the selected effect and shows its processing order and bypass state. The preview window groups Before, Preview and Intensity, and distinguishes temporary adjustments from effects already applied.

## 0.127.0 · 2026-11-22

Studio Graphite now extends to the timeline and playback controls. A time ruler and a shared playhead color make cuts easier to locate. Prepared frames appear in sage, with an amber hatch while a gap is being filled. Preview resolution, coverage and activity share a row when space allows.

## 0.126.0 · 2026-11-22

The composition header, monitor and inspector use the Studio Graphite palette. Document actions and canvas settings have distinct rows, with clearer headings and keyboard focus in the inspector.

## 0.125.1 · 2026-11-22

When editing intensity across multiple clips, the inspector shows how many clips it affects and where the other controls apply.

## 0.125.0 · 2026-11-22

Edit effect intensity across selected clips. Drag to preserve their differences or enter a shared percentage. Each edit has one undo step.

## 0.124.1 · 2026-11-22

Preview playback keeps the first soundtrack note continuous when starting a prepared loop at low frame rates.

## 0.124.0

The editor can load a local study catalogue. Projects, library preferences and render settings keep their existing formats. A standalone installation starts with an editable shape.
